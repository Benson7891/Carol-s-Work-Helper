# Carol's Work Helper

Carol 单人使用的个人事务管理器。纯静态网页，不需要安装，不连接原团队网站，也不会把数据上传到服务器。

## 使用

直接打开 `index.html`，使用 Carol 的邮箱和密码登录。数据保存在当前浏览器的本地存储中；换浏览器或换设备不会自动出现。

如果 Safari 直接打开文件时无法保存数据，可以在这个文件夹启动任意本地静态服务器后访问。

## 功能

- 工作台：紧急事项、本周到期、待推进事项和全部事项
- 事项列表：关键词、业务类型、状态、等待对象筛选
- 新建、编辑、删除、回收站恢复和彻底删除
- 完成当前步骤、撤销到上一步、撤回上次修改
- 文件链接和操作时间线
- 每周视图、打印／导出 PDF、导出 CSV 表格
- 简体中文、英文、西班牙文切换

## 单人版已移除

- 多账号和成员权限
- 项目成员、事项负责人和步骤负责人权限
- 聊天、通知、已读回执和系统通知
- 团队数据库与多设备同步

建议定期导出 CSV 作为备份。
